# 像素狗 (Pixel Dog) 功能设计文档

## 一、核心定位

像素狗是一个陪伴式虚拟宠物系统，通过完成现实目标（如番茄钟、待办事项）与用户一起成长，提供情感陪伴体验。

## 二、功能需求概览

| 模块 | 功能 | 实现位置 |
|------|------|----------|
| **成长系统** | 等级、经验值、升级奖励（动画/场景/家具） | ESP32 + 后端 |
| **羁绊系统** | 陪伴值、互动（摸摸头/摇尾巴）、每日唤醒 | ESP32 + 后端 |
| **情绪系统** | AI判断心情、根据任务/升级/互动变化 | ESP32本地判断 |
| **动画系统** | 行走、待机、高兴、睡觉等动画 | ESP32 |
| **陪伴系统** | 不定时问候、聊天（非专注时） | ESP32 + 后端 |

## 三、数据模型

### 3.1 DogState 结构体

```c
typedef struct {
    uint32_t level;          // 等级 (1-100)
    uint32_t xp;             // 当前经验值
    uint32_t xp_next;        // 升级所需经验值
    uint32_t bond;           // 陪伴值 (0-100)
    int8_t emotion;          // 情绪值 (-100~100, 负数低落, 正数开心)
    int64_t last_interact_ts;// 最后互动时间戳
    int64_t last_greet_ts;   // 最后问好时间戳
    uint8_t status;          // 状态: 0=idle, 1=walking, 2=happy, 3=sleeping, 4=eating
    uint8_t unlocked_items;  // 已解锁物品位掩码
} DogState;
```

### 3.2 升级所需经验值公式

```
xp_next = level * 100 + (level - 1) * 50
```

### 3.3 状态持久化 (NVS)

| 键名 | 类型 | 说明 |
|------|------|------|
| dog_level | uint32 | 等级 |
| dog_xp | uint32 | 经验值 |
| dog_bond | uint32 | 陪伴值 |
| dog_emotion | int8 | 情绪值 |
| dog_last_interact | int64 | 最后互动时间 |
| dog_last_greet | int64 | 最后问好时间 |
| dog_unlocked | uint8 | 已解锁物品 |

## 五、精灵动画设计

### 5.1 像素尺寸

- 精灵大小：16x16 像素
- 颜色数：4色（身体、眼睛、鼻子、项圈）

### 5.2 动画帧设计

#### 待机帧 (Idle)
```
帧0: 坐姿，尾巴下垂
帧1: 坐姿，尾巴微摇
```

#### 行走帧 (Walk)
```
帧0: 左腿在前
帧1: 右腿在前
帧2: 左腿在前
帧3: 右腿在前
```

#### 高兴帧 (Happy)
```
帧0: 尾巴快速摇摆
帧1: 身体跳跃
帧2: 尾巴快速摇摆
```

#### 睡觉帧 (Sleep)
```
帧0: 闭眼，Zzz符号
帧1: 呼吸起伏
```

### 5.3 动画引擎

- 使用 lv_timer 进行帧推进
- 每 200ms 更新一帧
- 支持状态切换时的动画过渡

## 八、交互流程

### 8.1 摸摸头

```
用户点击 → dog_pet() → emotion += 10 → bond += 1
                      → 播放高兴动画
                      → 显示随机回应文案
```

### 8.2 每日问好

```
用户点击 → dog_greet() → bond += 5
                      → 播放高兴动画
                      → 显示问候文案
                      → 更新 last_greet_ts
```

### 8.3 长时间未互动

```
tick检查 → 当前时间 - last_interact_ts > 3天
         → 显示关怀文案："最近是不是很忙呀？"
         → emotion -= 5（最多-20）
```

### 8.4 升级事件

```
xp >= xp_next → level++
              → xp -= xp_next
              → xp_next = level * 100 + (level - 1) * 50
              → emotion += 30
              → 播放庆祝动画
              → 解锁新内容（根据等级）
```

## 九、解锁内容规划

| 等级 | 解锁内容 |
|------|----------|
| 1 | 基础待机动画 |
| 5 | 行走动画 |
| 10 | 高兴动画 + 第一个家具 |
| 15 | 睡觉动画 |
| 20 | 新颜色皮肤 |
| 30 | 第二个家具 |
| 50 | 特殊庆祝动画 |
