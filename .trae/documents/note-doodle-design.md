# 笔记功能手绘风格界面设计方案（含文件夹分类）

## 1. 设计原则

参考首页 Scheme A 手绘风格，核心设计元素：

| 元素 | 风格特点 |
|------|---------|
| 边框 | SVG手绘不规则线条，圆角16px |
| 字体 | ZCOOL KuaiLe 手写字体 |
| 配色 | 奶油白 #faf8f5 背景，蓝色 #2563eb 主色 |
| 装饰 | 星星、波浪线、回形针 |
| 阴影 | 柔和阴影 0 4px 14px |

---

## 2. 数据结构

基于PC端 `NbTreeNode` 结构：

```typescript
interface NbTreeNode {
  nodeKey: string
  nodeType: 'FOLDER' | 'NOTE'
  name: string
  isPinned?: number
  children?: NbTreeNode[]
}
```

树状结构示例：
```
根目录
├── 工作笔记 (文件夹)
│   ├── 会议记录.md
│   ├── 项目规划.md
│   └── 设计文档 (子文件夹)
│       └── UI设计稿.md
├── 个人笔记 (文件夹)
│   ├── 学习笔记.md
│   └── 购物清单.md
└── 置顶笔记 (特殊分类)
    └── 重要事项.md
```

- 笔记卡片使用蓝色手绘边框
- 置顶笔记带有回形针和黄色装饰
- 点击文件夹卡片可展开/收起下属内容
- 搜索框使用胶囊形手绘边框

## 11. 方案对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 方案一：卡片式 | 视觉效果好，文件夹层级清晰 | 占用空间较大 | 文件夹数量适中 |
| 方案二：列表式 | 信息密度高，层级结构明确 | 视觉效果较弱 | 文件夹层级较深 |
| 方案三：导航+列表 | 切换方便，专注当前文件夹 | 需要多次点击 | 文件夹数量较多 |

**推荐方案：方案一（卡片式布局）** - 最符合手绘风格设计语言，视觉效果最佳，文件夹层级展示清晰。
