## 三层架构模式

### 1. 表现层（Presentation Layer）
- **PC端管理界面**：Vue 3 + Element Plus，完整的后台管理功能
- **移动端H5**：Vue 3 + 手绘涂鸦风格，适合手机端操作
- **ESP32副屏**：LVGL图形界面，番茄钟/歌词/像素狗展示

### 2. 业务逻辑层（Business Layer）
- Spring Boot Service层，处理核心业务逻辑
- 按业务域划分模块（电商、笔记本、番茄钟等）
- 支持定时任务、异步处理

### 3. 数据访问层（Data Access Layer）
- MyBatis-Plus ORM框架
- MySQL关系型数据库持久化
- Redis缓存实时状态数据

## 模块间通信方式

| 通信双方 | 协议 | 方式 | 说明 |
|---------|------|------|------|
| PC前端 → 后端 | HTTP/HTTPS | RESTful API | Axios封装，统一ApiResult格式 |
| 移动端 → 后端 | HTTP/HTTPS | RESTful API | 与PC端共用API |
| ESP32 → 后端 | HTTP | 轮询 + 上报 | 每1-2秒轮询会话状态，操作时立即上报 |
| 后端 → MySQL | TCP | JDBC | HikariCP连接池 |
| 后端 → Redis | TCP | Spring Data Redis | 番茄钟会话等实时数据 |

## 数据流示例

```

    │
    ▼

    ▼
```

### 笔记保存流程

```
编辑器内容变更
    │
    ▼
防抖触发保存
    │
    ▼
PUT /api/notes/{id}
    │
    ▼
后端: 
  1. 计算内容hash
  2. 更新元数据到MySQL
  3. 写入内容到存储（本地+百度网盘双写）
  4. 返回新版本号
    │
    ▼
前端更新本地状态
```

## 技术选型理由

### 后端
- **Spring Boot 3**: 成熟的企业级框架，生态丰富
- **MyBatis-Plus**: 简化CRUD开发，注解SQL灵活高效
- **Redis**: 实时会话同步的最佳选择，高性能+TTL自动过期
- **MySQL 8**: 关系型数据存储，事务支持

### 前端
- **Vue 3 + TypeScript**: 组合式API灵活，类型安全
- **Vite**: 极速开发体验
- **Element Plus**: 成熟的PC端组件库
- **Pinia**: 轻量状态管理
- **PWA支持**: 移动端可离线访问

### 固件
- **ESP-IDF**: 官方SDK，稳定性有保障
- **LVGL**: 开源嵌入式GUI，资源占用低
- **HTTP轮询**: 实现简单，适合设备状态同步
