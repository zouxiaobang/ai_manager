功能说明


- 入口：编辑器操作栏右侧新增的全屏按钮（<FullScreen /> 图标）

- 两种笔记类型都支持：

 - HTML 笔记：直接渲染编辑器的 HTML 正文

 - MD 笔记：通过 marked.parse() 渲染后的预览 HTML

- 全屏界面：

 - 半透明模糊遮罩 + 居中白色卡片面板（92vw × 88vh，max 960×800）

 - 顶部栏：笔记标题 + "Esc 退出" 提示 + 关闭按钮

 - 正文区域：舒适排版（16px 字号，1.8 行距，宽适 padding 40px）

 - Escape 键 / 点击遮罩 / 关闭按钮均可退出

 - 入场缩放+上移动画

- 富文本样式覆盖：标题、段落、代码块、引用、表格、列表、图片均做了阅读优化
